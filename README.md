我的时间记录
一个纯前端、单文件、零依赖的时间记录网页：按项目记录每天投入的时间段，追踪每日目标完成度，并把「被打断的时间」单独归到系统项目「杂事」。手机上打开即用，数据只存在本机浏览器，不上传、不需要账号。
- 在线页面：https://www.oktime.cc/
- 本地文件：我的时间记录.html（约 2100 行 / 94 KB，内联 CSS + 内联 JS）
快速开始
双击 我的时间记录.html，用 Chrome / Edge / Safari 等现代浏览器打开即可。无需安装、无需构建、无需联网、无需服务器。
首次打开会自动创建一个系统项目「杂事」，其余项目由你通过右上角「＋」新建。数据保存在当前浏览器的 localStorage 中，键名为 my-time-records:v1。
换浏览器、换设备、无痕窗口、清除浏览器数据都会导致数据不可见或丢失。重要数据请定期用页面底部的「导出记录」备份成 CSV。

功能详解
项目与排序
- 新建项目名最多 10 个字、不可与现有项目重名；颜色从 8 色调色板依次分配。
- 每个项目有 sortIndex，数值越大越靠前；新建时取当前时间戳，因此总在普通项目的第一位。
- 「杂事」不参与排序，永远固定在列表最底部。
- 新建完成后自动滚动到新卡片、短暂浅蓝底高亮约 1 秒淡出，并紧接着弹出目标时长设置面板（取消按钮显示「暂不设置」）。
- 修改目标、开始 / 中断 / 结束、撤销记录、生成记录卡、删除项目都不改变任何项目的 sortIndex；删除后其余项目保持原值，不重排。（当前 ⋯ 菜单只提供「修改目标时长」和「删除项目」，普通项目暂无改名入口。）
- 旧数据缺 sortIndex 时，按当前显示顺序重新赋值（第一个最大、依次递减 100）；重复值按原数组顺序稳定排序，结果写回本地存储，下次直接读取。

中断与「杂事」
点「中断」从底部弹出轻量面板：
- 第一行四个快捷原因：喝咖啡休息 / 接电话 / 临时被叫走 / 处理杂事。点一下回填输入框，再点一次取消选中。
- 选填输入框「补充说明」，最多 20 字。
- 两个按钮：「中断并开始记杂事」（实心）、「只中断」（描边）。
- 点面板外空白处、下滑关闭、按 Escape，都等同于「只中断」且不填备注、不弹二次确认。
- 「只中断」闭合当前段并写入备注；空内容不保存空备注。
- 「中断并开始记杂事」闭合当前段，同时立刻开始一段「杂事」，其 sourceProject 记为被中断项目名，备注自动填「因《项目名》中断」加补充内容。
之后点任意项目的「开始 / 继续」时，若杂事正在计时，会自动把杂事段闭合在当前时刻，不弹窗，状态条浮现「杂事已记录 XX 分钟」。
「杂事」是系统项目：固定中性灰 #9CA3AF、固定在列表最后；不可删除、不可改名、不可设置每日目标；⋯ 菜单只保留「清空今日记录」。首次打开和读取旧数据时都会自动补齐；若旧数据里已有同名普通「杂事」，会原地升级、合并记录，不丢数据。
在最新的单行布局下，「杂事」被渲染成一条紧凑横条：从左到右是灰色竖条 →「杂事」→「开始」，右侧「今日暂无记录」（有记录时显示「今日合计 XX」）、虚线圆形减号、⋯ 保持最右端右对齐，不再有独占一行的按钮，也没有右下角空白。

规则：不足 60 分钟显示分钟数 +「分」；整小时显示小时数 +「时」；其余显示一位小数 +「时」。
未设目标时显示 40px 浅灰虚线圆 +「＋」，点击它直接弹出目标时长设置面板，与 ⋯ 菜单里的「修改目标时长」完全同一入口，保存后圆圈变为实线显示数字。「杂事」位置是静态虚线圆 +「—」，不可点击。
目标时长以「小时（023）+ 分钟（059）」输入，合计为 0 分钟视为未设置，不计入目标总时长。圆形图标与按钮都用透明 padding 把点击区域撑到 44×44px / 44px 高，视觉尺寸不变，方便手指点击。
今日记录
- 按开始时间从新到旧排列，默认只显示最近 5 条；超过 5 条时底部出现「展开全部（共 N 条）」，点击展开、再点「收起」。展开状态是纯 UI 变量，不写入数据、展开收起不改任何记录。
- 当天没有记录时显示一行「今天还没有记录」。
- 每段显示项目色圆点、项目名、HH:MM–HH:MM（进行中显示「现在」）、分钟数，以及「计时中」/「中断」状态标签。
- 有备注时在时长后显示小灰字标签；由中断产生的杂事行显示「← 阅读」样式的来源标记。备注超过 8 个字折叠显示，点这一行展开全文、再点收起。
- 每段右侧「×」可撤销该段，弹确认框；删除后时长会从项目合计、今日总时长、圆环与百分比中同步扣除。
项目名过长时单行省略号截断，不会撑破卡片布局。
今日概览与统计口径
- 今日各项目小计：按项目列出当天时长，各项目分开计算。
- 今日合计：所有项目所有段相加，包含杂事和未设目标的项目，格式为 HH:MM。
- 其中杂事 XX 分钟：仅在有杂事记录时显示的小灰字。
- 目标总时长：所有设置了目标的项目目标之和；全部未设目标时显示「未设置目标」。
- 完成百分比：只按设置了每日目标的项目计算，分子是这些项目今天已投入之和，分母是它们目标时长之和；杂事和没设目标的项目都不参与。保留一位小数（如 16.7%），超过 100% 照实显示。
- 圆环按完成比例绘制，0% 时弧长严格为 0；旁边显示「还差 X 分钟」/「已完成目标」/「已超出 X 分钟」。
举例：阅读目标 2 小时，10:00–10:10 阅读后中断去记杂事，10:20 继续阅读，10:30 结束。结果为阅读 20 分钟、杂事 10 分钟、今日合计 30 分钟（含杂事），而完成百分比为 20/120 = 16.7%（杂事不计入分子分母）。
生成今日记录卡 / 导出记录
- 生成今日记录卡：弹窗预览一张 Canvas 绘制的 PNG（750px 宽、2 倍位图），包含昵称、日期与星期、今日总时长、目标完成百分比、进度条、「其中杂事 XX 分钟」、今日各项目小计列表。可点「保存图片」下载，移动端支持长按图片保存到相册。
- 导出记录：把全部历史（不止今天）导出为 UTF-8 BOM 的 CSV（防中文乱码），文件名为 我的时间记录-YYYY-MM-DD.csv，共 8 列：
  日期 / 项目 / 开始 / 结束 / 时长(分钟) / 状态 / 备注 / 来源项目
  其中状态为「计时中 / 中断 / 完成」，进行中的段结束时间显示「进行中」。导出只读数据，不改动任何记录与统计。无记录时提示「暂无记录可导出」。

设计与实现要点
- 单文件：HTML + 内联 <style> + 内联 <script>，零第三方库、零外部字体、零网络请求。
- 移动端优先：内容最大宽度 480px，适配 env(safe-area-inset-*) 刘海屏；按钮与图标点击区不小于 44px；360px 以下屏幕自动缩小中断面板按钮字号。
- 事件委托：只在 document 上绑定一次 click / keydown，通过 data-action 分发；render() 重建 DOM 不会重复绑定。
- 同源计算：一次 render() 只取一次 now 并向下传递，所有合计、圆环、百分比来自同一个 computeDayStats() 结果。
- XSS 防护：项目名称、昵称、备注、来源项目等用户输入进入 innerHTML 前统一经 esc() 转义。
- Canvas 记录卡：2 倍位图绘制，文字超长自动缩放适配。
- 自测接口：window.TTR 暴露 getState / setStateForTest / render / computeDayStats 等方法，方便在浏览器控制台做本地验证，不影响界面。
- 托管标记：文件头部的 /page/page_comm/inject.js 与各元素上的 data-page-node-id 属性是 WorkBuddy 资料库托管环境注入的，本地直接打开时该脚本加载失败不影响任何功能。
使用注意
- 无账号、无云同步；清除浏览器数据 / 无痕窗口 / 换设备会导致数据不可见或丢失，请用「导出记录」备份。
- 删除项目会连带删除该项目所有记录且无法恢复；删除单段记录同样不可恢复。
- 全局只有一个进行中段，开始别的项目会自动结束当前段，无需二次确认。
- 项目名最多 10 字且不可重名；「杂事」为保留的系统项目，不可删除、改名或设目标。
- 备注最长 50 字，中断面板「补充说明」最长 20 字，来源项目名最长 10 字。
- 刷新后总是回到页面顶部；展开 / 收起「今日记录」不影响任何数据。
